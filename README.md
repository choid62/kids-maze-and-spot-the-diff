# Play Time (미로랑 틀린그림)

5살 아이를 위한 놀이 13가지 앱입니다: 미로, 틀린그림, 숨은그림, 짝 맞추기, 다음은?(규칙 찾기), 영어 단어 잇기, 버스 정류장, 몬스터 밥 주기, 10 만들기, 젓가락(손가락) 놀이, 코코넛 크랙, 틱택토, 가위바위보. 문제는 매번 새로 자동 생성되고, 인터넷 없이도 동작합니다.

미국 친구들과 같이 놀 수 있게 **화면 글자와 목소리는 모두 영어**입니다 (앱 이름 Play Time). 코드 주석과 이 문서는 한국어입니다.
핸드폰 브라우저에서 "홈 화면에 추가"로 설치하는 웹앱(PWA)이라서 안드로이드와 아이폰 모두에서 쓸 수 있습니다.

## 바로 해 보기

```
npm start          # 웹 서버 실행 → http://localhost:8080
npm test           # 미로·틀린그림 생성기 테스트
```

PC에서는 `index.html`을 더블클릭해서 열어도 됩니다.
같은 와이파이에 연결된 핸드폰에서는 `npm start` 실행 후 화면에 나오는 `http://192.168.x.x:8080` 주소로 열 수 있습니다.

## 핸드폰에 설치하기

오프라인 실행과 "홈 화면에 추가"는 **https 주소**에서만 제대로 동작합니다. 무료 호스팅에 올리는 것을 추천합니다.

- GitHub Pages: 저장소에 올린 뒤 Settings → Pages → 브랜치 `main` / 폴더 `/ (root)` 선택
- 또는 Netlify Drop(app.netlify.com/drop)에 이 폴더를 끌어다 놓기

설치 방법:

| 폰 | 방법 |
| --- | --- |
| 안드로이드 (Chrome) | 주소를 열고 메뉴 → "홈 화면에 추가" 또는 "앱 설치" |
| 아이폰 (Safari) | 주소를 열고 공유 버튼 → "홈 화면에 추가" |

한 번 열고 나면 인터넷 없이도 실행됩니다.

## 홈 화면

놀이를 세 묶음으로 나눠 보여 줍니다: **Look & Find**(미로, 틀린그림, 숨은그림), **Think & Learn**(짝 맞추기, 다음은?, 단어 잇기), **Numbers**(버스 정류장, 몬스터 밥 주기, 10 만들기 — 덧셈·뺄셈), **Play Together**(젓가락, 코코넛, 틱택토, 가위바위보 — 로봇이나 친구와). 태블릿 가로 화면에서는 네 묶음이 나란히 세로줄로 놓입니다. 부모 설정(⚙️, 덧셈 문제를 맞혀야 열림)에서 "✏️ Choose games on the home screen" 을 누르면 홈이 고르기 모드가 되어 모든 게임이 보이고, 게임 타일을 누를 때마다 켜짐(✓)/꺼짐(✖, 흐리게)이 바뀝니다. 위쪽 Done ✓ 을 누르면 꺼 둔 게임은 홈에서 사라지고, 묶음의 게임이 모두 꺼지면 묶음 제목도 숨겨집니다. 이 설정은 기기에 저장되고 "Start Over" 를 해도 그대로입니다.

## 놀이 방법

- **미로**: 캐릭터(토끼, 벌, 물고기, 자동차)를 손가락으로 끌어 목표까지 데려갑니다. 벽에 부딪혀도 실패가 없고, 되돌아가면 지나온 길이 지워집니다. 위쪽 ↩️ 버튼을 누르면 같은 미로에서 지나온 길을 지우고 출발점으로 돌아갑니다 (잘못 들어갔을 때 처음부터), 🔄 는 새 미로.
- **틀린그림**: 위아래 그림에서 다른 곳을 누릅니다. 판을 시작하거나 마지막으로 차이를 찾은 뒤 1분이 지나면 힌트가 저절로 반짝입니다 (그냥 누르는 것은 시간을 되돌리지 않음, 힌트 버튼은 없음).
- **젓가락 놀이**: 내 손으로 상대 손을 치면 상대 손에 내 손가락 수만큼 더해지고, 5개 이상이 되면 그 손은 죽습니다. 양손이 다 죽으면 집니다. 칠 때마다 펴진 손가락을 1, 2, 3 … 하나씩 센 뒤, 내 손의 수와 상대 손의 수가 손가락에서 튀어나와 가운데 식의 빈칸으로 날아가 "1 + 3 = 4"를 만들고, 손이 손을 톡 친 뒤 답이 식에서 맞는 손으로 날아가 그 손이 바뀝니다. 식은 다음 사람이 칠 때까지 남아 있습니다. 한 손이 죽었고 다른 손이 2나 4일 때만 "나누기"를 눌러 반씩 나눌 수 있습니다 (0+2 → 1+1, 0+4 → 2+2). 100수가 넘으면 비깁니다.
  - **로봇이랑**: 쉬움/보통/어려움. 로봇은 모든 상황(225가지)을 미리 풀어 두고, 쉬움은 30%, 보통은 70%, 어려움은 항상 최선의 수를 둡니다. 이 규칙은 둘 다 완벽하게 두면 비깁니다. 판마다 먼저 두는 쪽을 번갈아 바꿉니다. 이기면 스티커를 받습니다.
  - **둘이서**: 한 폰을 가운데 두고 마주 앉아 합니다. 위쪽 사람 화면은 거꾸로 보입니다.
- **코코넛 크랙**: 코코넛이 큰 원 위에 시계 방향으로 놓이고 모두 가운데를 바라봅니다. "Coco·nut, Coco·nut, Coco·nut, Crack!" 7박자에 맞춰 시계 방향으로 코코넛을 하나씩 칩니다. 7번째(Crack!)에 걸린 코코넛이 한 단계 바뀝니다: 통 코코넛 → 쩍 갈라져 반쪽 두 개(하얀 속살) → 걸린 반쪽은 우유가 쏟아져 빈 껍질 → 다시 걸리면 사라짐. 코코넛이 다 사라지면 탈락, 끝까지 남으면 이깁니다.
  - 시작 고르기: 내 코코넛을 누르고, 같은 코코넛을 한 번 더 누르면 거기서부터, 바로 다음(시계 방향) 코코넛을 누르면 그 옆에서부터 셉니다. 갈라진 두 반쪽 중 어느 쪽이든 고를 수 있습니다.
  - 다음에 세는 사람은 방금 걸린 사람입니다 (탈락했으면 시계 방향 다음 사람).
  - 남은 사람 모두 코코넛이 하나씩이고 모양이 같으면(반쪽끼리, 우유 쏟은 것끼리) 비깁니다. 그때는 먼저 세는 사람이 이길 수밖에 없기 때문입니다. 처음의 통 코코넛 하나씩은 해당하지 않습니다.
  - **합치기**: 내 차례에 우유 쏟은 반쪽이 두 개면 "🥥 합치기"를 눌러 다시 통 코코넛 하나로 만들 수 있습니다. 한 사람당 한 판에 한 번만 할 수 있습니다. 컴퓨터는 합칠 수 있으면 항상 합칩니다. 혹시 80번 넘게 걸리면 비깁니다.
  - **1:1** 또는 **1:1:1**(나 + 컴퓨터 2명). 컴퓨터 난이도: 쉬움(아무 데나), 보통(자기 코코넛 피하기), 어려움(자기 코코넛 피하고 아이 코코넛을 노리며 다음 차례까지 생각; 1:1은 모든 상황을 미리 풀어 두고 85%의 차례에서 최선의 수).
- **틱택토**: 3x3 판에 번갈아 그림을 놓고(나 = 토끼, 로봇, 친구 = 곰돌이) 가로·세로·대각선 세 개를 먼저 한 줄로 놓으면 이깁니다. 이긴 세 칸이 하나씩 반짝입니다. 로봇이랑(쉬움: 아무 데나, 이길 자리도 절반은 놓침 / 보통: 이길 수 있으면 이기고 막아야 하면 막음 / 어려움: 끝까지 계산해서 절대 지지 않음) 또는 둘이서. 새 판마다 먼저 두는 쪽이 바뀝니다.
- **가위바위보 (Rock Paper Scissors)**: 로봇이랑 또는 둘이서(태블릿을 사이에 두고 마주 앉아, 위쪽 화면은 뒤집힘). 바위 ✊ / 보 ✋ / 가위 ✌️ 를 누르면 "Rock, paper, scissors, shoot!" 을 보통 말하는 속도로 말하고, 화면의 단어와 주먹 흔들기를 목소리에 맞춥니다. "Shoot!" 하는 순간 고른 손이 펼쳐지고, 말이 끝나면 누가 이겼는지 나옵니다 (기기가 단어 알림을 주면 그 순간에, 아니면 지난번에 잰 말 길이를 4박자로 나눠서). 말이 다 끝난 뒤에 동시에 펼쳐집니다. 둘이서는 먼저 고른 사람은 "Ready ✓" 만 보이고 손은 숨겨집니다. 이긴 이유(Rock breaks scissors! 등)를 보여 주고 읽어 주며, 별 3개를 먼저 모으면 승리. 로봇은 아무거나 냅니다. 손 그림은 Fluent Emoji (`assets/rps/`).
- **단어 잇기 (Words)**: 왼쪽에 영어 단어 3개, 오른쪽에 그림 3개가 섞여 나옵니다. 단어에서 그림으로 손가락을 끌어 줄을 긋거나, 단어와 그림을 차례로 눌러 잇습니다. 맞히면 짝마다 다른 색 줄이 남고 그 단어를 영어로 읽어 줍니다. 한 판 5문제. 영어 단어는 배우기 전에는 올라가도 못 하므로 레벨은 저절로 올라가지 않습니다 (맞는 레벨을 계속 복습, 바꿀 때는 위쪽 레벨 표시를 눌러 고름). 레벨 1~5는 글자 수(3, 4, 5, 6, 7글자 이상), 레벨 6은 모든 단어. 단어 270개 중 한 번도 안 나왔거나 가장 오래전에 나온 단어부터 나오므로(기기에 기록), 그 레벨의 단어를 다 보기 전에는 같은 단어가 다시 나오지 않습니다. 서로 비슷해 보이는 그림 묶음(자동차·택시, 오리·거위, 쥐·햄스터 등)은 한 문제에 같이 나오지 않습니다.
- **버스 정류장 (Bus Stop)**: 동물 친구들이 탄 버스가 정류장에 서면 몇 마리가 더 타고(+) 내립니다(−). 타고 내릴 때 1, 2 … 숫자가 붙고 위에 +2 / −1 이 크게 나옵니다. 버스가 터널에 들어가면 지금 몇 마리인지 보기 3개 중에서 고르고, 아래에는 식이 계속 보입니다: 처음 수 → 정류장마다 + 2, − 1 이 붙고, 터널에서는 "3 + 2 − 1 = ?". 맞히면(또는 두 번 틀리면) 버스가 터널을 나와 한 마리씩 세고 ? 가 답으로 바뀝니다. 한 판 5문제, 4문제 이상 한 번에 맞히면 레벨 업. 레벨 1~2 더하기, 3 빼기, 4 섞기, 5~6 정류장 두 곳(최대 10마리).
- **몬스터 밥 주기 (Feed Me!)**: 몬스터가 "I want 5 strawberries!" 라고 하고 접시에 2개가 있으면, 아래 식 "2 + ? = 5" 와 "How many more?" 를 보고 보기 3개 중에서 고릅니다. 보기는 숫자가 아니라 음식 그림 개수(5개씩 한 줄)라서 세어 보고 고릅니다 (그냥 누르며 맞추면 계산이 필요 없어서 객관식). 접시가 너무 많으면 "7 − ? = 4", "How many should we take away?". 틀리면 그만큼이면 모자란지(Still hungry!) 많은지(Too many!) 몬스터가 알려 주고, 맞히면(또는 두 번 틀리면) 통에서 1, 2, 3 세며 하나씩 놓거나 덜어 낸 뒤 몬스터가 먹습니다. 접시는 늘 1개 이상. 레벨 1~3 더 주기(1~2는 말풍선에 원하는 수만큼 그림), 4 덜어 내기, 5~6 섞기(6은 접시 수 표시 없음). 한 판 5문제, 4문제 이상 한 번에 맞히면 레벨 업.
- **10 만들기 (Make 10)**: 앞면이 보이는 숫자 카드(숫자 + 열 칸 점)에서 더해서 목표 수가 되는 두 장을 고릅니다. 위의 식 빈칸이 채워지고, 맞으면 "3 and 7 make 10!". 레벨 1은 5 만들기, 2는 6 … 6~7은 10 만들기(7은 0 카드도). 어떤 짝을 먼저 맞혀도 남은 카드는 늘 짝이 맞습니다. 실수 2번 이하면 레벨 업.
  - 1:1은 둘 다 완벽하게 하면 처음 세는 사람이 이깁니다. 판마다 처음 세는 사람을 돌아가며 정합니다.
- **숨은그림 (Hidden)**: 장면 하나에서 위쪽 목록의 3글자 영어 단어(예: cat 0/2)에 맞는 물건을 정해진 수만큼 찾습니다. 찾을 물건은 단어 게임의 3글자 단어 그림 32개(눈·귀·다리·해 제외) 중에서 나오고, 비슷해 보이는 그림(car·van 등)은 함께 나오지 않습니다. 레벨 1~10, 물건 10~30개, 찾을 단어 1~4개. 레벨 5부터 물건이 겹칩니다. 찾을 물건은 앞 물건에 가려지지 않게 만들고, 같은 그림의 방해 물건은 없습니다. 2분 동안 안 누르면 힌트.
- **짝 맞추기**: 카드를 두 장씩 뒤집어 같은 그림을 찾습니다. 혼자(레벨 1~10, 카드 6~30장, 쌍끼리는 모두 다른 그림) 또는 로봇이랑(맞히면 한 번 더, 로봇이 본 카드를 기억할 확률: 쉬움 35%, 보통 70%, 어려움 100%).
- **다음은?**: 🍎🍌🍎🍌❓ 처럼 규칙을 보고 빈칸에 들어갈 것을 고릅니다. 한 판 5문제, 한 번에 4문제 이상 맞히면 레벨 업. 레벨이 오르면 규칙이 길어지고(AB → AAB, ABB → ABC → AABB → ABCD), 빈칸이 중간으로 가고, 그림은 같고 색이나 크기만 바뀌는 규칙이 나옵니다 (방향이나 눈처럼 미묘한 차이는 쓰지 않음).
- 끝낼 때마다 스티커를 하나 받고, ⭐ 버튼으로 스티커 북을 봅니다.
- 홈 오른쪽 위 ⚙️ → 덧셈 문제를 풀면 부모 설정이 열립니다 (소리, 목소리, 단계 조절, 초기화).

## 레벨

화면 위쪽과 홈 버튼에 현재 레벨이 표시됩니다 (예: "레벨 3 · 쉬움"). 게임 화면 위쪽의 레벨 표시를 누르면 원하는 레벨을 고를 수 있습니다.

| 레벨 | 구분 | 미로 (짧은 변) | 틀린그림 |
| --- | --- | --- | --- |
| 1~3 | 쉬움 | 4~6칸 | 물건 8~10개, 차이 3~4개 |
| 4~6 | 보통 | 7~9칸 | 물건 11~12개, 차이 4~5개, 6부터 작은 물건 |
| 7~8 | 어려움 | 10~11칸 | 물건 13~14개, 차이 6개, 8부터 크기 차이가 미묘해짐 |
| 9~10 | 아주 어려움 | 12~13칸 | 물건 14개, 차이 7개 |
| 11~15 | 최고 (틀린그림만) | - | 물건 16~20개가 서로 겹침, 차이 7~9개 |

레벨 11부터는 줄을 촘촘히 엇갈려 놓아 물건이 겹칩니다. 앞 물건에 가려져서 바뀐 곳이 안 보이는 차이는 만들지 않습니다.

미로는 끝낼 때마다 한 레벨씩 올라갑니다. 틀린그림은 힌트 없이 끝냈을 때만 올라갑니다. 부모 설정에서 직접 바꿀 수도 있습니다.

## 틀린그림 장면과 차이

장면은 공원, 바다, 농장, 우주, 눈 마을, 생일 파티, 동물원 7가지이고, 같은 장면이 연달아 나오지 않습니다.
그림은 Microsoft Fluent Emoji 121종을 씁니다.

차이는 레벨에 따라 아래 순서로 열립니다. 레벨이 높을수록 작은 차이가 더 자주 나옵니다.

| 레벨 | 새로 나오는 차이 |
| --- | --- |
| 1 | 없애기, 다른 물건으로 바꾸기, 색 바꾸기, 크기, 빈자리에 추가 |
| 3 | 좌우 뒤집기, 무늬 생기기/없어지기, 동그란 눈이 웃는 눈으로 |
| 4 | 부분 색 바꾸기 (예: 앵무새 부리), 부분 커지기 (예: 게 집게) |
| 5 | 무늬 모양 바꾸기 (예: 점박이가 하트로) |
| 6 | 부분 없애기 |
| 7 | 부분 각도 바꾸기 (예: 새 날개, 꼬리) |

### 배경

공원, 농장, 동물원, 눈 마을은 Kenney 배경 조각으로 배경을 만듭니다. 하늘과 구름층, 먼 언덕이나 설산, 땅 위에 지평선 소품(나무, 집, 성, 탑, 덤불, 울타리, 선인장) 4~6개를 매번 다르게 놓습니다.
지평선 소품도 차이가 될 수 있습니다 (한 판에 1~2개까지, 이모지에 가려진 소품은 제외).

| 레벨 | 배경 차이 |
| --- | --- |
| 2 | 소품 없애기 |
| 3 | 같은 종류의 다른 소품으로 바꾸기 (나무 → 다른 나무) |
| 4 | 색 버전 바꾸기 (초록 지붕 → 빨간 지붕, 초록 나무 → 주황 나무) |
| 6 | 소품 좌우 뒤집기 |

바다, 우주, 생일 파티는 코드로 그린 배경을 씁니다.

그림마다 몸통, 눈, 부분(날개, 집게, 귀 등)을 `tools/build-emoji.js`가 자동으로 찾습니다.
실제로 보이는 면적을 계산해서, 가려져서 티가 안 나는 차이는 만들지 않습니다.

## 그림 추가하기

1. `tools/emoji-list.js`에 Fluent Emoji 폴더 이름을 추가합니다.
2. 저장소 파일 목록을 받고 그림을 내려받습니다.
   `curl -sSL -o tree.json "https://api.github.com/repos/microsoft/fluentui-emoji/git/trees/main?recursive=1"`
   `node tools/fetch-emoji.js tree.json`
3. `node tools/build-emoji.js`로 `js/emoji-data.js`를 다시 만듭니다.
4. `js/scene.js`의 장면 목록(THEMES)에 이름을 넣습니다.
5. `tools/gallery.html?mode=face` 또는 `?mode=parts`를 브라우저로 열어 변형이 자연스러운지 확인합니다.

### 단어 게임 단어 추가하기

1. `js/words.js`의 WORDS에 `{ w: '단어', e: 'Fluent Emoji 폴더 이름' }`을 넣습니다 (헷갈리는 그림이 있으면 같은 `g` 묶음).
2. 위의 tree.json으로 `node tools/fetch-words.js tree.json` (없는 그림만 `assets/words/`에 받음).
3. `npm test`로 그림 파일과 중복을 확인합니다.

## 자가 점검용 주소

주소 뒤에 붙이면 정해진 문제와 동작을 볼 수 있습니다.

- `?seed=5&level=3#maze` 같은 시드와 단계의 미로
- `?demo=drag#maze` 손가락으로 끄는 동작을 흉내 내 미로를 끝까지 풂
- `?theme=sea&demo=tapall#spot` 바다 장면에서 차이를 모두 누름
- `?demo=hint#spot` 힌트 표시
- `?demo=chopplay#chop` 젓가락 놀이를 로봇과 끝까지 둠 (사람 쪽은 실제 버튼을 누름), `?demo=chopduo#chop` 둘이서 한 판
- `?demo=coco2#coco`, `?demo=coco3#coco` 코코넛 크랙 1:1, 1:1:1 한 판 (내 차례는 실제 코코넛을 누름)
- `?demo=tttplay#ttt` 틱택토를 로봇과 끝까지 둠 (사람 쪽은 실제 칸을 누름), `?demo=tttduo#ttt` 둘이서 한 판, `?demo=tttwin#ttt` 이기는 한 수
- `?demo=wordsplay#words` 단어 잇기 한 판을 끝까지 (문제마다 한 번 틀리고, 끌어서 잇기와 차례로 누르기를 모두 씀), `?level=5#words` 레벨 지정
- `?demo=busplay#bus`, `?demo=monsterplay#monster`, `?demo=tenplay#ten` 숫자 놀이 한 판씩 (일부러 한 번씩 틀림), `?level=4#bus` 처럼 레벨 지정
- `?demo=rpsplay#rps` 가위바위보 로봇과 한 판, `?demo=rpsduo#rps` 둘이서 한 판
- `?demo=reset#maze` 미로를 가다가 ↩️ 로 처음으로
- `?demo=settings` 부모 설정 창 열기, `?demo=gamesoffedit` 고르기 모드에서 Maze 와 Play Together 게임을 끈 모습, `?demo=gamesoff` 끄고 Done 한 홈 (기기에 저장되니 다시 켜 두기)
- `?demo=cocomerge#coco` 합치기 버튼이 나오는 상태, `?demo=cocomergeplay#coco` 합치고 끝까지 한 판
- `?demo=memosolo#memo`, `?demo=memobot#memo` 짝 맞추기 한 판 (실제 카드를 누름)
- `?demo=hiddenplay#hidden` 숨은그림 한 판, `?demo=patternplay#pattern` 다음은? 한 판
- `?demo=picker#spot` 레벨 고르기 창 열기, `?demo=pick12#spot` 레벨 12 고르기
